ফর্ম পূরণ করুন

নিচের ফর্মে আপনার নাম, ইমেইল, অ্যাপের নাম আর কী কাজে লাগবে লিখুন।

আমরা দেখি

সাধারণত ১ থেকে ৩ দিনের মধ্যে অনুরোধ যাচাই করে দেখা হয়।

ইমেইলে key

অনুমোদন হলে key ইমেইলে পাঠানো হয়। তারপর থেকেই ব্যবহার শুরু।

কী করতে পারবেন, কী পারবেন না

key নেওয়ার মানে আপনি নিচের সব নিয়ম মেনে নিচ্ছেন। নিয়ম ভাঙলে কোনো নোটিশ ছাড়াই key বন্ধ করা হবে।

যা করতে পারবেন

  • নিজের অ্যাপ, ওয়েবসাইট, স্মার্ট ঘড়ি বা মসজিদের ডিসপ্লেতে ডেটা দেখানো।
  • নিজের মতো ডিজাইন, নিজের নাম আর নিজের লোগো দিয়ে অ্যাপ বানানো।
  • ফ্রি অ্যাপে বা বিজ্ঞাপনসহ অ্যাপে ব্যবহার করা।
  • ফোনে ২৪ ঘণ্টা পর্যন্ত ডেটা জমা (cache) রাখা, যাতে অফলাইনেও চলে।
  • দরকার হলে বেশি limit বা নতুন অংশের জন্য আবার অনুরোধ করা।

যা করতে পারবেন না

  • "Salah Time" নাম, লোগো, আইকন বা আমাদের অ্যাপের হুবহু ডিজাইন ব্যবহার করা, বা নিজেকে Salah Time বলে দেখানো।
  • key অন্য কাউকে দেওয়া, বিক্রি করা, বা খোলা জায়গায় (GitHub ইত্যাদি) রেখে দেওয়া।
  • সব ডেটা একসাথে নামিয়ে নিজের API বানিয়ে আবার বিক্রি করা।
  • দোয়া, হাদিস বা আয়াতের লেখা বদলে দেওয়া, বা উৎস মুছে দেওয়া।
  • ইসলামের পরিপন্থী, ঘৃণা ছড়ানো, প্রতারণা বা জুয়ার কাজে ব্যবহার করা।
  • দিনের সীমার বেশি request পাঠাতে একাধিক key বা কৌশল ব্যবহার করা।
যা আমরা কখনো দিই না

Salah Time-এর ব্যবহারকারীদের কোনো তথ্য (লোকেশন, ফোন, মতামত, কিছুই না), এডমিন প্যানেলে ঢোকার সুযোগ, অ্যাপের সোর্স কোড, আজানের অডিও ফাইল আর আমাদের ডিজাইন।

সীমা

সাধারণত প্রতি key দিনে ৫,০০০ request। রাত ১২টায় (UTC) আবার শুরু হয়। বেশি লাগলে কারণ লিখে জানান।

নাম উল্লেখ করুন

যেখানে ডেটা দেখাবেন, সেখানে ছোট করে লিখুন: "তথ্য: Salah Time"। কনটেন্টের ক্ষেত্রে মূল উৎসও রাখুন।

নামাজের সময় জ্যোতির্বিজ্ঞানের হিসাবে বের করা। এলাকার মসজিদের জামাতের সময় কয়েক মিনিট আলাদা হতে পারে। রমজান আর হিজরি তারিখ শেষ পর্যন্ত চাঁদ দেখার উপর নির্ভর করে। API যেমন আছে তেমনভাবে দেওয়া হয়, আর যেকোনো সময় বদলাতে বা বন্ধ হতে পারে।

প্রশ্ন ও উত্তর

    
API কি ফ্রি?
হ্যাঁ, এখন সাধারণ ব্যবহারের জন্য ফ্রি। খুব বেশি ব্যবহার হলে আলাদা করে কথা বলা হবে।

    
key হারিয়ে ফেললে কী করব?
নিরাপত্তার জন্য key আমরাও আর দেখতে পারি না। আবার ফর্ম পূরণ করে জানান যে আগের key হারিয়েছে, পুরানটা বন্ধ করে নতুন key দেওয়া হবে।

    
ওয়েবসাইটের JavaScript-এ key রাখলে অন্যরা দেখে ফেলবে না?
দেখতে পারে। তাই ওয়েবসাইটে ব্যবহার করলে অনুরোধে লিংক দিন। আমরা key-টা শুধু আপনার ওয়েবসাইট থেকে চলার মতো করে দেব। মোবাইল অ্যাপে key কোডের ভেতরে রাখুন, প্রকাশ্যে রাখবেন না।

    
নামাজের সময় কতটা ঠিক?
Salah Time অ্যাপ যে হিসাব ব্যবহার করে, এটাও হুবহু তাই (করাচি পদ্ধতি, হানাফি আসর)। তবু এলাকার মসজিদের জামাতের সময় আলাদা হতে পারে।

    
Salah Time-এর মতো একটা অ্যাপ বানাতে পারব?
হ্যাঁ, নিজের নাম, নিজের ডিজাইন আর নিজের লোগো দিয়ে। শুধু আমাদের নাম, লোগো বা হুবহু ডিজাইন ব্যবহার করবেন না।
