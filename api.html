প্রশ্ন ও উত্তর

    
API কি ফ্রি?
হ্যাঁ, সাধারণ ব্যবহারের জন্য পুরোপুরি ফ্রি।

    
key হারিয়ে গেলে?
আবার ফর্ম পূরণ করে জানান। পুরানটা বন্ধ করে নতুন key দেওয়া হবে।

    
ওয়েবসাইটে key রাখলে অন্যরা দেখবে না?
লিংক দিলে key-টা শুধু আপনার ওয়েবসাইট থেকে চলার মতো করে দেব।

    
সময় কতটা ঠিক?
Salah Time অ্যাপের হুবহু একই হিসাব (করাচি পদ্ধতি, হানাফি আসর)। মসজিদের জামাতের সময় একটু আলাদা হতে পারে।
